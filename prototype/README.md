# Cidex prototype (preview)

Single-file preview of the site. Not the live site (that is `public/`).

Run locally:

    cd prototype
    python3 -m http.server 8080

Then open http://localhost:8080 in a browser. The 3D hero and page
fonts load from CDNs, so you need internet access.

Preview limits: contact, subscribe and profile forms do not send anything
yet; Aetheria and Clow give scripted answers; Account data is saved on the
device only.
